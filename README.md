# 🚗 INFINITE DRIVE

### Endless Free Driving Experience

**INFINITE DRIVE** is a relaxing 3D endless driving game designed for PC and Android. Explore beautiful roads, enjoy different environments, and drive freely without racing, traffic, or time limits.

## 🎮 Game Features

- 3D Driving Environment
- Endless Road System
- Compact Hybrid Car
- Aqua-style Compact Car
- Electric Pickup / Cybertruck-style Car
- Forest Road
- Mountain Road
- Bridge Road
- Summer and Night Modes
- Rainy Weather
- Winter Environment
- Speedometer (KM/H)
- Steering, Acceleration and Brake Controls
- PC Keyboard Controls
- Android Touch Controls
- Pause and Resume System

## 🕹️ Controls

| Action | PC Keyboard |
|---|---|
| Accelerate | W / ↑ |
| Brake | S / ↓ |
| Steer Left | A / ← |
| Steer Right | D / → |
| Pause | Pause Button |

Android users can use the on-screen driving buttons.

## 💻 Supported Platforms

- Windows PC – Web Browser
- Android – Web Browser
